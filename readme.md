## 🌟 Descripción del Proyecto
Plataforma web profesional e independiente para la administración logística, contratos de alquiler, vencimientos, mantenimiento técnico y remitos en PDF de la flota de 50 contenedores de **SG MONTAJES S.R.L.**

---

## 🚀 Características Principales
- **Tablero Ejecutivo & KPIs**: Ocupación en tiempo real, alertas de vencimiento y facturación estimada.
- **Inventario Completo (50 Unidades)**: Seguimiento de módulos (*C-101 a C-150*).
- **Asignación Rápida de Alquileres**: Generación y extensión de contratos de alquiler a 30 días.
- **Tablero de Taller & Mantenimiento**: Seguimiento de reparaciones con checklist técnico.
- **Mapa Geográfico Interactivo**: Despliegue en obras y Base Operativa Timbúes.
- **Emisión de Remitos Oficiales**: Generación instantánea en PDF para Entrega y Retiro.
- **Panel de Configuración**: Gestión de usuarios, datos de la empresa y copias de seguridad JSON.
- **Sincronización Dual**: Funciona de forma local con LocalStorage o conectado a Supabase en la nube.

## 💻 Instalación y Uso Rápido
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/sg-contenedores.git
   ```
2. Abrir directamente `index.html` en cualquier navegador web.
3. Credenciales predeterminadas:
   - **Usuario**: `melani`
   - **Contraseña**: `123`

---

## ☁️ Configuración de Supabase
1. Cree un proyecto en [Supabase](https://supabase.com).
2. Ejecute el script `schema_supabase_contenedores.sql` en el **SQL Editor** de Supabase.
3. Configure su `SUPABASE_URL` y `SUPABASE_ANON_KEY` en `supabase_config.js`.
